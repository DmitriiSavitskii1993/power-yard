# 🚗 Power Yard — Telegram Mini App (калькулятор растаможки авто)

Расчёт стоимости авто «под ключ» при ввозе в РФ из 🇰🇷 **Кореи** и 🇪🇺 **Европы**
(включая электрокары): пошлина, утильсбор, акциз и НДС для электро, корейский НДС
и его возврат, таможенный сбор, расходы по РФ, комиссия и этапы оплаты.

Логика перенесена из Google-таблицы «Киндер Калькулятор» и сверена на контрольных
примерах (см. `tests/test-calc.js`). Курсы ЦБ подтягиваются автоматически
(cbr-xml-daily.ru), рыночные курсы (₩/USDT, USDT/₽, € продажа) вводятся вручную
и запоминаются.

## Структура

```
index.html      — разметка Mini App (2 экрана: калькулятор + настройки)
css/style.css   — оформление (палитра «Киндер» поверх темы Telegram)
js/data.js      — все ставки и таблицы (пошлины, утиль, акциз, сбор, пресеты)
js/calc.js      — движок расчёта (чистые функции, работает и в Node)
js/rates.js     — курсы ЦБ, localStorage + Telegram CloudStorage
js/app.js       — логика интерфейса
bot/bot.js      — Telegram-бот (grammY) + HTTP-эндпоинт /prepare для «📤 В чат»
tests/          — контрольные цифры: node tests/test-calc.js
img/            — генераторы иконки и обложки (открыть в браузере → скриншот)
```

## Отличия от исходной Google-таблицы (исправления)

1. **Европа**: в таблице таможенная стоимость считалась по курсу **юаня**
   (остаток от китайского шаблона), а ставка 2.5 €/см³ / 54% / сбор 2 462 ₽ были
   захардкожены. Здесь таможенная стоимость считается по курсу ЦБ **EUR**, брекеты
   пошлины и сбора — полноценные формулы. На авто 20 000 € разница ~3.3× (в
   таблице пошлина была занижена).
2. **Корея**: единая база таможенной стоимости = (цена + доставка + дилерские) ×
   курс ЦБ ₩ (в таблице проценты и брекеты считались от разных баз). На
   контрольном примере итог совпадает с таблицей: пошлина+сбор 633 215 ₽.
3. Этапы оплаты — без двойного учёта логистики (в таблице этап 4 считал её дважды).

## Деплой (по шагам)

### 1. Бот у BotFather

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` →
   имя «Киндер Калькулятор», username вида `kinder_calc_bot`.
2. Сохранить **токен** (передавать безопасно, не в открытом чате).
3. После деплоя фронта (шаг 2): `/setmenubutton` → выбрать бота → указать URL
   приложения и подпись «Калькулятор» (или это сделает сам бот при первом запуске).
4. По желанию `/newapp` → привязать Mini App: загрузить иконку 640×360
   (`img/cover.html` → скриншот) и задать short name.

### 2. Фронтенд — GitHub Pages

1. Создать репозиторий (например `kinder-calc`), залить все файлы проекта.
2. Settings → Pages → Source: `main`, папка `/ (root)`. Файл `.nojekyll` уже есть.
3. Приложение будет доступно по `https://<аккаунт>.github.io/kinder-calc/`.

### 3. Бот — Render (для кнопки «📤 В чат»)

1. [render.com](https://render.com) → New → **Web Service** → подключить репозиторий.
2. Runtime: Node. Build: `npm install`. Start: `npm start`.
3. Environment: `BOT_TOKEN` (из шага 1), `WEBAPP_URL` (адрес Pages из шага 2).
4. После деплоя вписать адрес сервиса (например
   `https://kinder-calc-bot.onrender.com`) в константу `BACKEND_URL` в начале
   `js/app.js` и закоммитить.

Без Render всё тоже работает: «📤 В чат» отправит текстовую версию через
`t.me/share`, а «📋 Копировать» кладёт расчёт картинкой в буфер.

## Настройки внутри приложения

- **Курсы на сегодня** (главный экран): ₩ за 1 USDT, USDT → ₽, € продажа —
  сохраняются сразу и запоминаются (localStorage + облако Telegram).
- **⚙️ Настройки**: курсы ЦБ (кнопка «Обновить» тянет свежие), ставки
  пошлины/НДС электрокаров.
- Дефолтные расходы (доставка по Корее 1 300 000 ₩, дилерские 440 000 ₩, брокер,
  логистика и т.д.) правятся в `js/data.js` → `korea`, `europe`, `expensePresets`.
