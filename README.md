# 🚗 Power Yard — Telegram Mini App (калькулятор растаможки авто)

Расчёт стоимости авто «под ключ» при ввозе в РФ из 🇰🇷 **Кореи**, 🇪🇺 **Европы**
и 🇨🇳 **Китая** (включая электрокары): пошлина, утильсбор, акциз и НДС, корейский
НДС и его возврат, таможенный сбор, расходы по РФ, комиссия и этапы оплаты.

**Схемы растаможки** (выпадающий список, у каждой своя формула):
- **Физлицо РФ** — единые ставки ЕТС (пошлина по возрасту/объёму, льготный утиль).
- **Юрлицо** — коммерческий импорт: тамож. стоимость по курсу ЦБ+3%, пошлина 15% +
  акциз + НДС 22% + полный утильсбор + сбор.
- **Через КГ (Киргизия) / через Белку (Беларусь)** — ручной ввод стоимости
  растаможки ($ / €) + логистика; калькулятор складывает.

**Валюты** — выпадающим списком: Корея ₩/$, Европа €, Китай $/¥ (по курсу ВТБ).
**CIF СПб** (Китай) — цена уже с доставкой. **Финансирование** — галочка + месяцы,
+2%/мес к сумме под ключ.

Логика сверена на контрольных примерах (см. `tests/test-calc.js`). Курсы ЦБ
подтягиваются автоматически (cbr-xml-daily.ru); рыночные курсы (₩/USDT, USDT/₽,
€ продажа, $/¥ ВТБ) вводятся вручную и запоминаются.

## Структура

```
index.html      — разметка Mini App (2 экрана: калькулятор + настройки)
css/style.css   — оформление (палитра «Киндер» поверх темы Telegram)
js/data.js      — все ставки и таблицы (пошлины, утиль, акциз, сбор, пресеты)
js/calc.js      — движок расчёта (чистые функции, работает и в Node)
js/rates.js     — курсы ЦБ, localStorage + Telegram CloudStorage
js/app.js       — логика интерфейса
bot/bot.js      — Telegram-бот (grammY) + HTTP-эндпоинт /prepare для «📤 В чат»
tests/          — контрольные цифры: node tests/test-calc.js
img/            — генераторы иконки и обложки (открыть в браузере → скриншот)
```

## Отличия от исходной Google-таблицы (исправления)

1. **Европа**: в таблице таможенная стоимость считалась по курсу **юаня**
   (остаток от китайского шаблона), а ставка 2.5 €/см³ / 54% / сбор 2 462 ₽ были
   захардкожены. Здесь таможенная стоимость считается по курсу ЦБ **EUR**, брекеты
   пошлины и сбора — полноценные формулы. На авто 20 000 € разница ~3.3× (в
   таблице пошлина была занижена).
2. **Корея**: единая база таможенной стоимости = (цена + доставка + дилерские) ×
   курс ЦБ ₩ (в таблице проценты и брекеты считались от разных баз). На
   контрольном примере итог совпадает с таблицей: пошлина+сбор 633 215 ₽.
3. Этапы оплаты — без двойного учёта логистики (в таблице этап 4 считал её дважды).

После `git push` в `main` сайт обновляется автоматически (1–2 мин).

### Бот — Render

Проще всего через Blueprint (файл `render.yaml` уже в репозитории):

1. [render.com](https://render.com) → New → **Blueprint** → подключить репозиторий
   `power-yard`. Render прочитает `render.yaml` и создаст сервис `power-yard-bot`.
2. Задать переменные: **`BOT_TOKEN`** (из `bot/.env`) и **`ALLOWED_USERS`** —
   список Telegram ID через запятую, кому разрешён бот. `WEBAPP_URL` уже в blueprint.
3. Deploy. После старта скопировать адрес сервиса (напр.
   `https://power-yard-bot.onrender.com`) в константу `BACKEND_URL` в начале
   `js/app.js`, закоммитить и запушить — заработает кнопка «📤 В чат».

### Доступ к боту (whitelist)

Бот пускает только Telegram ID из `ALLOWED_USERS` (через запятую); пусто → открыт
всем. **Обязательно добавь свой ID**, иначе сам не войдёшь — узнать через
[@userinfobot](https://t.me/userinfobot). Пример: `ALLOWED_USERS=73390717,<твой_id>`.

Без Render всё тоже работает: «📤 В чат» отправит текстовую версию через
`t.me/share`, а «📋 Копировать» кладёт расчёт картинкой в буфер.

### BotFather

- `/setmenubutton` → выбрать бота → URL `https://dmitriisavitskii1993.github.io/power-yard/`,
  подпись «Калькулятор» (либо это сделает сам бот при первом `/start`).
- По желанию `/newapp` → привязать Mini App: обложку 640×360
  (`img/cover.html` → скриншот) и иконку (`img/icon.html`).

## Настройки внутри приложения

- **Курсы на сегодня** (главный экран): ₩ за 1 USDT, USDT → ₽, € продажа —
  сохраняются сразу и запоминаются (localStorage + облако Telegram).
- **⚙️ Настройки**: курсы ЦБ (кнопка «Обновить» тянет свежие), ставки
  пошлины/НДС электрокаров.
- Дефолтные расходы (доставка по Корее 1 300 000 ₩, дилерские 440 000 ₩, брокер,
  логистика и т.д.) правятся в `js/data.js` → `korea`, `europe`, `expensePresets`.
